## Decision Principles

- [Proven] I/O, time, subprocess, filesystem, and facade mutation stay Shell because `INVAR.md` explicitly assigns those effects to Shell.
- [Proven] Pure logic that transforms already available data should move to `src/vectl/core/**` and must receive `@pre`, `@post`, and doctest before implementation.

- [Likely] Existing broad `@invar:allow shell_result` comments on pure helpers should not become permanent budget policy; they should be replaced by structural extraction where the function has no Shell effect and returns ordinary domain values.
